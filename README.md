## 📂 Projetos em Destaque

### Blog Pessoal Spring

API REST desenvolvida com **Java** e **Spring Boot**, aplicando conceitos de desenvolvimento backend, persistência de dados, relacionamento entre entidades e organização em camadas.

O projeto representa a construção de uma aplicação backend estruturada, com foco em boas práticas, separação de responsabilidades e criação de endpoints para manipulação de dados.

**Tecnologias utilizadas:** Java, Spring Boot, MySQL, JPA/Hibernate, API REST e Git.

**Repositório:** [blogpessoal_spring](https://github.com/Brassaroto/blogpessoal_spring)

---

### Kavio CRM — Backend

Backend do **Kavio**, um sistema de gestão CRM desenvolvido em equipe como projeto final do Bootcamp Java Full Stack da Generation Brasil.

A aplicação foi construída para fornecer a base da regra de negócio e da comunicação com o frontend, utilizando **Java** e **Spring Boot** para criação de APIs REST, organização das entidades, persistência de dados e estruturação do sistema.

O projeto reforçou minha experiência com desenvolvimento backend, trabalho em equipe, versionamento com Git e integração entre diferentes camadas de uma aplicação full stack.

**Tecnologias utilizadas:** Java, Spring Boot, MySQL, JPA/Hibernate, API REST e Git.

**Repositório:** [projeto_03_backend](https://github.com/Cavaleiros-Templarios/projeto_03_backend)

---

### Kavio CRM — Frontend

Frontend do **Kavio**, sistema de gestão CRM desenvolvido em equipe como projeto final do Bootcamp Java Full Stack da Generation Brasil.

Atuei no desenvolvimento da interface da aplicação, utilizando **React**, **TypeScript**, **Tailwind CSS** e **Vite**, com foco na criação de telas funcionais, responsivas e integradas ao backend por meio de APIs REST.

Esse projeto consolidou minha experiência com desenvolvimento frontend moderno, componentização, consumo de APIs, organização de código e colaboração em equipe.

**Tecnologias utilizadas:** React, TypeScript, JavaScript, Tailwind CSS, Vite, API REST e Git.

**Repositório:** [projeto_03_frontend](https://github.com/Cavaleiros-Templarios/projeto_03_frontend)
